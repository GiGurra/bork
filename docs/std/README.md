# Standard packages

Standard packages are imported as `bork/name` and ship with the compiler
(no `bork.mod` needed). Each package page contains its API, examples and limits.
See the [package table](../../README.md#standard-packages) for the full list.

[Go helper API](../std-go.md) documents shared standard-package implementation contracts.

When adding a package, add its page here and one row to the README package table.

[bork/tasks](tasks.md) provides shared bounded task pools with explicit admission failures.
