# Syntax trials

What would bork look like if it adopted another language's syntax? The
same program (types with facts, a sealed type, a union result, a method,
lambdas and chains, a map, interpolation, a scope, unsafe Go, and a test)
written in each language's own syntax and idioms, keeping bork's
semantics. GitHub highlights each with that language's grammar.

- [bork as it is](bork/sample.bork)
- [Scala 3](scala/sample.bork)
- [Rust](rust/sample.bork)
- [Go](go/sample.bork)
- [Kotlin](kotlin/sample.bork)
- [Swift](swift/sample.bork)
- [TypeScript](typescript/sample.bork)
- [V](v/sample.bork)
- [Zig](zig/sample.bork)
- [Gleam](gleam/sample.bork)
- [Hare](hare/sample.bork)
- [Cairo](cairo/sample.bork)
- [Mojo](mojo/sample.bork)

Each file starts with a note on how bork's concepts map to the language,
and what stays bork's where the language has no counterpart.
